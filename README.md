# شَدّ

لعبة لوحية ثلاثية الأبعاد: مُدّ الشريط المطاطي على أربعة أوتاد في خط مستقيم، أغلق أضلاع المثلثات الصغيرة، وضع قطعتك فيها. الأكثر مثلثات يفوز.

- **العب الآن**: افتح `game/shadd.html` في المتصفح (أو `index.html` عند تفعيل GitHub Pages).
- 2 إلى 4 لاعبين على جهاز واحد، أو **أونلاين من جوالات مختلفة** (غرفة بكود من 4 حروف أو رابط دعوة أو QR).
- مؤقت ١٠ ثوانٍ لكل دور (إذا خلص الوقت يروح الدور) · كمبيوتر بثلاثة مستويات · ثلاثة أحجام للوح · واجهة عربية.
- أربعة ألواح (أسود، كحلي، خشب، جرانيت أخضر) · خلفية فاتحة أو داكنة · 8 ألوان للاعبين.

## اللعب أونلاين
1. واحد يفتح اللعبة ← «أونلاين» ← يكتب اسمه ويختار لونه ← «إنشاء غرفة».
2. يرسل رابط الدعوة أو الكود للباقين، وكل واحد يفتح الرابط من جواله ويضغط «انضمام».
3. المضيف يحدد عدد المقاعد (2 إلى 4) ويضغط «ابدأ». المقاعد الفارغة يلعبها الكمبيوتر.

- الاتصال مباشر بين الأجهزة (WebRTC عبر PeerJS)، بدون سيرفر خاص. المضيف هو المرجع، فخلّ شاشته مفتوحة.
- إذا انقطع لاعب، يلعب الكمبيوتر عنه، وإذا رجع بنفس الجوال للرابط يرجع لمقعده.
- بعض الشبكات (شركات، فنادق، بعض شبكات الجوال) تمنع الاتصال المباشر. جرّبوا بيانات الجوال أو واي فاي ثاني.

## محتويات المستودع
| المسار | الوصف |
|---|---|
| `game/shadd.html` | النسخة الجاهزة للعب (Three.js، ملف واحد) |
| `docs/GDD.md` | وثيقة تصميم اللعبة |
| `unity/Assets/Scripts/` | منطق اللعبة بلغة C# وطبقة العرض في Unity (لم تُختبر في المحرر بعد) |
| `blender/build_shadd_assets.py` | سكربت يبني اللوح والأوتاد والقطع ويصدّرها FBX (لم يُختبر بعد) |

تشغيل سكربت Blender:
```
blender --background --python blender/build_shadd_assets.py -- --radius 4 --out ./export
```
