# شَدّ

لعبة لوحية ثلاثية الأبعاد: مُدّ الشريط المطاطي على أربعة أوتاد في خط مستقيم، أغلق أضلاع المثلثات الصغيرة، وضع قطعتك فيها. الأكثر مثلثات يفوز.

- **العب الآن**: افتح `game/shadd.html` في المتصفح (أو `index.html` عند تفعيل GitHub Pages).
- 2 إلى 4 لاعبين · كمبيوتر بثلاثة مستويات · ثلاثة أحجام للوح · تلميح · واجهة عربية.

## محتويات المستودع
| المسار | الوصف |
|---|---|
| `game/shadd.html` | النسخة الجاهزة للعب (Three.js، ملف واحد) |
| `docs/GDD.md` | وثيقة تصميم اللعبة |
| `unity/Assets/Scripts/` | منطق اللعبة بلغة C# وطبقة العرض في Unity (لم تُختبر في المحرر بعد) |
| `blender/build_shadd_assets.py` | سكربت يبني اللوح والأوتاد والقطع ويصدّرها FBX (لم يُختبر بعد) |

تشغيل سكربت Blender:
```
blender --background --python blender/build_shadd_assets.py -- --radius 4 --out ./export
```
